# 🎬 Módulo de Películas para Odoo 17
Este módulo permite gestionar una base de datos de películas dentro de Odoo, incluyendo información como título, género, director, duración y año de estreno.

# 📦 Requisitos
Odoo 17.0

Python 3.8 o superior

## ⚙️ In stalación
Clona el repositorio en tu directorio de addons:

bash
Copiar
Editar
git clone https://github.com/RangerSheff/movie_odoo_test.git
Reinicia el servidor de Odoo.

Activa el modo desarrollador en Odoo.

Ve a Apps, actualiza la lista de aplicaciones y busca Movie Module.

Instala el módulo.

# 🧩 Uso
Una vez instalado:

Accede al menú Películas en el panel principal.

Desde allí, puedes:

Crear nuevas entradas de películas.

Editar o eliminar películas existentes.

Visualizar la lista de películas en vista de lista o formulario.

# 🛠️ Configuración
No se requiere configuración adicional para el uso básico del módulo. Sin embargo, puedes personalizar los permisos de acceso según las necesidades de tu organización.

# 🚧 Problemas Conocidos
Actualmente, el módulo no incluye funcionalidades avanzadas como reseñas de usuarios o integración con bases de datos externas de películas.

La interfaz está disponible únicamente en inglés.
